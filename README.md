# ポートフォリオ公開サイト

HTML,CSS,JavaScriptを用いて制作するポートフォリオサイトです。
Webサイトの制作に加え、Git・GitHubによるバージョン管理や、GitHubFlowを用いた開発手法の習得を目的としています。

## 公開サイト

**URL:**[https://Ayato-Ikeda.github.io/](https://Ayato-Ikeda.github.io/)

GitHub Pagesを利用して公開しています。

## 使用技術・開発環境
- フロントエンド ...HTML5, CSS3, JavaScript
- 開発環境 ...Eclipse IDE
- バージョン管理 ...Git/GitHub
- 開発フロー ...GitHub Flow
- ホスティング ...GitHub Pages

## 開発・バージョン管理
開発にはGitHub Flowを採用しています。

バージョン管理は[Semantic Versioning](https://semver.org/lang/ja/)を参考に管理し、リリース時にはGitタグとGitHub Releasesを利用します。

## 変更履歴・リリース情報
各バーコードの変更履歴は、Keep a Changelogを参考に`CHANGELOG.md`で管理しています。

- **[CHANGELOG.md](CHANGELOG.md)**_バージョンごとの変更内容
- **[GitHub Release](https://github.com/Ayato-Ikeda/Ayato-Ikeda.github.io/releases)**
- リリースノート・Gitタグ・ソースコード
